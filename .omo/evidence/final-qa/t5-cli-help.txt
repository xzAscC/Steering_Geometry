usage: steering_geometry.extract [-h] --concept {polite,refusal,sentiment}
                                 [--model MODEL]
                                 [--method {mean,pca,weighted_mean,discriminative}]
                                 [--num-pairs NUM_PAIRS] [--top-k TOP_K]
                                 [--output OUTPUT] [--dry-run]
                                 [--layers LAYERS [LAYERS ...]]
                                 [--data-mode {prompt_only,prompt_response}]
                                 [--token-select {all,last_n}]
                                 [--last-n LAST_N] [--seed SEED]

Extract steering vectors for behavioral concepts

options:
  -h, --help            show this help message and exit
  --concept {polite,refusal,sentiment}
                        Concept to extract (sentiment, refusal, polite)
  --model MODEL         HuggingFace model name (default: sshleifer/tiny-gpt2)
  --method {mean,pca,weighted_mean,discriminative}
                        Extraction method (default: mean)
  --num-pairs NUM_PAIRS
                        Number of contrast pairs (default: 500)
  --top-k TOP_K         Top-k tokens for discriminative method (default: 100)
  --output OUTPUT       Output directory (default: data/vectors/)
  --dry-run             Load data only, skip model loading and extraction
  --layers LAYERS [LAYERS ...]
                        Relative layer positions (e.g., --layers 0.5 or
                        --layers 0.4 0.5 0.6)
  --data-mode {prompt_only,prompt_response}
                        Data formatting mode for refusal concept (default:
                        prompt_only)
  --token-select {all,last_n}
                        Token selection strategy (default: all)
  --last-n LAST_N       Number of tokens for last_n mode (default: 1)
  --seed SEED           Random seed for deterministic subsampling (default:
                        42)
